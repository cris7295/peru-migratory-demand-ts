# Módulos reutilizables

- `calidad.py`: esquema, claves, meses, años y cantidades estrictos.
- `carga.py`: carga completa de los ocho originales; falla ante archivos faltantes.
- `transformacion.py`: panel histórico y vista separada de componentes del carné.
- `auditoria.py`: evidencia descriptiva y referencias predictivas a h=1,2,3.
- `versiones.py`: snapshots sin sobrescritura y comparación de revisiones.

protocolo propuesto y `reports/auditoria_pre_modelado.md` para evidencia y pendientes.
