# src/

Aquí van funciones de Python reutilizables (no notebooks): limpieza de datos, la regla de
exclusión para no contar dos veces los trámites de "Carné - Cambio de Calidad", el armado del
panel mensual, funciones para entrenar y evaluar los modelos Prophet, etc.

La idea: si una misma pieza de código se va a usar en más de un notebook, en vez de copiarla y
pegarla varias veces, se escribe una sola vez aquí y se importa donde se necesite.
